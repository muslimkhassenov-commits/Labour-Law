# Ассеты для интерактивного модуля

Положите сюда два файла с точными именами — модуль (`index.html` / `zanyatie1-v2.html`)
подхватит их автоматически. Пока файлов нет, вместо них показываются
CSS-заглушки в фирменных цветах MNU, поэтому страница уже полностью рабочая.

| Файл                | Что это                                              | Где используется                          |
|---------------------|-------------------------------------------------------|--------------------------------------------|
| `mnu-logo.png`       | Логотип Maqsut Narikbayev University (с прозрачным фоном, PNG) | Шапка, обложка, подвал                     |
| `mnu-campus.jpg`     | Фотография кампуса MNU (горизонтальная, ≥1600px по ширине)     | Фон обложки, атмосферные плашки разделов   |

Формат и вес: PNG для логотипа (лучше с альфа-каналом), JPG для фото (оптимизируйте
до ~300–500 КБ, чтобы страница быстро грузилась на телефоне).
